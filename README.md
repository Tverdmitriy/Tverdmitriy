## 💼 Проекты

### 🎵 [Информационная система анализа музыкальных предпочтений](https://github.com/Tverdmitriy/music-preferences-db)
> Курсовой проект по проектированию БД

- **Стек:** `C#` · `Windows Forms` · `MySQL` · `ADO.NET`
- Спроектировал реляционную БД с нуля: **10+ таблиц**, нормализация до **3НФ**, ER-модель в нотации Питера Чена.
- Реализовал бизнес-логику на уровне СУБД: **5 триггеров** (расчёт весов `weight = 6 − rank`), **7 хранимых процедур**, **5 представлений (Views)**.
- Разработал десктопное приложение с 8 формами: каталог песен, участники, опросы, аналитика, формирование пластинок.
- Оптимизировал производительность: **8+ индексов** (поисковые, составные, по внешним ключам).

### ♟️ [Десктопная игра «Шахматы»](https://github.com/Tverdmitriy/chess-qt)
> Учебный проект по C++ и Qt *(код будет добавлен позже)*

- **Стек:** `C++` · `Qt 6 (Qt Widgets)` · `QPainter` · `CMake`
- Реализовал архитектуру с разделением ответственности: **модель** (двумерный массив 8×8), **визуализация** (`paintEvent`), **контроллер** (`mousePressEvent`).
- Написал алгоритмы валидации ходов для всех 6 типов фигур с учётом препятствий и правил взятия.
- Добавил механику **превращения пешки** (диалог выбора фигуры) и условие победы при взятии короля.
- Кастомная отрисовка доски 640×640 px через `QPainter` и `QPixmap`.
